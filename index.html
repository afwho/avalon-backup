what matters.

Avalon Backup is a personal-use backup utility that securely stores encrypted server backups in the owner's Google Drive account.

01

Encrypted before upload

Backup contents are encrypted on the server using Restic before transfer to Google Drive.

02

Limited Drive access

Rclone uses Google OAuth with the drive.file permission for backup files created or accessed through this application.

03

Owner-controlled

This is not a public backup service. There are no public accounts, subscriptions or backup downloads on this website.

About this website

This public page describes the application's purpose and data practices for its Google OAuth configuration. It does not host backup contents or provide access to the backup system.
