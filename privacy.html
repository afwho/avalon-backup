DATA PRACTICES

Privacy policy.

Last updated 13 October 2026

Avalon Backup is a private utility used by its owner to create, store, verify and restore encrypted backups of a personal server. It is not offered to other users.

1. Google data accessed

When the owner authorizes Google Drive access, the backup client uses the https://www.googleapis.com/auth/drive.file scope. This permits access to Drive files the application creates or opens for use with it, rather than general access to unrelated Drive documents. The client also uses OAuth credentials to authenticate subsequent backup operations.

2. How data is used

The sole purpose of Google Drive access is to upload, list, check, download, retain and remove the encrypted files that make up the owner's Restic backup repository. The application does not use Google Drive data for advertising, profiling or unrelated purposes.

3. Encryption and storage

Backup content is encrypted with Restic before being uploaded. Encrypted repository files reside in the owner's Google Drive account. Backup source files may remain on the owner's server. OAuth tokens and the backup encryption password are stored on the owner's server in access-restricted configuration files to support unattended backups. Google Drive is not used to store the plaintext backup password.

4. Sharing and external services

Backups are not sold or intentionally shared with third parties. Google provides Drive storage and API access; the server hosting provider processes operations on the owner's server; and GitHub Pages serves this informational website. These providers may process limited technical information according to their own policies. No advertising or analytics scripts are installed on this website.

5. Retention and deletion

Encrypted backup files are retained according to the owner's configured backup-retention policy and available Drive storage. The owner may delete backup files in Google Drive, revoke the application's Google account access, or remove its OAuth credentials at any time. Revoking access stops future automated uploads until authorization is renewed; it does not automatically delete existing backup files.

6. Security and access

The backup system is restricted to the owner's administrative environment. Backup encryption limits exposure of stored backup contents, but no method of storage or transmission is guaranteed to be completely secure. This public site does not contain credentials, backups or access to the server.

7. Contact and changes

This is a single-owner personal-use application. Questions about its Google Drive access can be directed to the app owner using the support contact identified on the Google OAuth consent screen. This policy may be updated if the application's data-handling practices change.
